# 📑 Academic & Project Reports

This directory stores the final project reports, documentation summaries, and academic deliverables generated for the **Design and Implementation of a Wazuh-Based SOC Home Lab for Attack Detection and Log Analysis**.

---

## 📂 Report Files

| File | Format | Description |
| :--- | :--- | :--- |
| [`Final_Report.pdf`](Final_Report.pdf) | PDF Document | Comprehensive final academic project report detailing lab design, VM setups, attack detection workflows, findings, and conclusions. |

---

## 📊 Summary of Report Contents

1. **Executive Summary**: Objectives, scope, and key deliverables of the SOC Home Lab.
2. **System Architecture**: VM setup on Oracle VirtualBox, NAT Network layout, Wazuh server specification.
3. **Telemetry & Log Collection**: Sysmon configuration, Windows Event Channels, File Integrity Monitoring.
4. **Attack Simulation & Detection**: Nmap scanning, Hydra brute-forcing, PowerShell monitoring, and Wazuh alert validation.
5. **Incident Investigation**: Wazuh Dashboard visualization, MITRE ATT&CK mapping, and threat hunting workflows.
6. **Troubleshooting & Observations**: Lessons learned, common errors, service management, and future enhancements.
